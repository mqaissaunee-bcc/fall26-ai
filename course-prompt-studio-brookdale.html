    Step 4 of 8

    Learning outcomes

    Choose the Institutional Learning Outcomes (ILOs) this course develops, type in your Program Learning Outcomes (PLOs), and align each lesson to the outcomes it supports.

    Institutional Learning Outcomes (ILOs)

    Brookdale's Institutional Learning Outcomes are loaded, in the order of the NJCC general education goals. Turn on each one the course develops; rename or remove them only if the published list changes. Add a sentence on how, if you want the team to use your wording.

    Course Learning Outcomes

    Paste the Course Learning Outcomes from the official Brookdale course syllabus or the catalog, one per line. The team uses this wording exactly and writes lesson objectives that build toward them. Find them in the Brookdale catalog (opens in new tab) ↗.

    Program Learning Outcomes (PLOs)

    Type each PLO as your program publishes it. The team uses your wording exactly and will not invent PLOs. The verb bank helps when you are drafting new ones.

    Practice and assessment

    Optional. Add worked examples and Canvas quizzes to the plan, then hand them to the companion tools that build them. Leave both off and the prompts cover the homepage and plan only.

    Worked examples

    For problem-solving courses: math, science, engineering, technology, economics, accounting. Each lesson gets a page of step-by-step solutions built with the Quantitative Exam Builder (opens in new tab) ↗.

    Settings

    Hand off to the exam builder

    Each file carries the course title, audience, outcomes, units, significant figures, and one problem slot per lesson or example. In the exam builder, choose Load Saved Exam (JSON).

    Export the in-class presenter page and save it as examplesNN.html, where NN is the lesson number (examples03.html for lesson 3).
